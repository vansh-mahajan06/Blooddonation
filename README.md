# 🩸 Blood Donation - Find Donors, Save Lives

A simple and fast web platform to connect **blood donors** with **patients in urgent need** of blood.

One donation can save up to **3 lives**.

🔴 **Live Website:** https://blooddonation-326.vercel.app/

---

## ✨ Features

- 🔍 **Search Donors** by Blood Group and City / Location
- 🩸 **Register as a Donor** - Add your name, blood group, phone, and city
- 🚨 **Request Blood** - Create an urgent blood request for a patient
- 📱 **Mobile Friendly** - Works on phone, tablet and desktop
- ⚡ **Fast & Lightweight** - Deployed on Vercel
- ❤️ **100% Free** - Made for social good, no charges
